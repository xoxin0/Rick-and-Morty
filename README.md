# Rick and Morty App

Веб-приложение для просмотра информации о персонажах из мультсериала "Рик и Морти", созданное с использованием Angular 19.

## Технологии

- **Angular**: 19.1.0
- **TypeScript**: 5.7.2
- **RxJS**: 7.8.0

## Установка и запуск

1. Установка зависимостей:
```bash
  npm install
```
2. Запуск сервера разработки:
```bash
  ng serve
```
Приложение будет доступно по адресу `http://localhost:4200/`.

## Возможности

- Просмотр списка персонажей, локаций и эпизодов Rick and Morty
- Детальная информация о персонажах, локациях и эпизодах
- Поиск и фильтрация персонажей, локаций и эпизодов
- Адаптивный дизайн для мобильных устройств
